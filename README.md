# UnityPackageManager
- UPM 仓库是为了给Unity提供安装Package的仓库。
- 其中App.Frame和App.3rds是UnityAppFramework框架（[GitHub](https://github.com/Josh-Jun/UnityAppFramework)/[Gitee](https://gitee.com/shijun_z/UnityAppFramework)）核心代码和三方插件Package
